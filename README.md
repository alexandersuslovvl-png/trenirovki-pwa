# Тренировки — PWA

Офлайн-трекер тренировок по программе A/B/C (верх тела + пресс):
- подходы с весом и повторами;
- время начала и окончания каждого упражнения;
- таймер отдыха с вибрацией;
- в карточке каждого упражнения — анимация техники, тренажёр, схема рабочих мышц;
- экспорт тренировки в Markdown для дневника Obsidian.

Без сборки и зависимостей: статические файлы, ES-модули, service worker.
Спецификация — [docs/spec.md](docs/spec.md).

## Структура
| Файл | Что внутри |
|---|---|
| `js/data.js` | Упражнения (тексты из атласа Obsidian, тренажёр, мышцы, картинки) и программа A/B/C |
| `js/store.js` | Хранение тренировок в `localStorage` |
| `js/app.js` | Экраны и действия |
| `js/muscles.js` | SVG-схема мышц |
| `js/export.js` | Экспорт в Markdown и JSON |
| `sw.js` | Офлайн-кэш (генерируется `tools/build_sw.py`) |

## Изменения
После любой правки файлов пересобери `sw.js`:

```bash
python tools/build_sw.py
```

Иначе телефон продолжит показывать старую версию из кэша.

## Запуск локально
```bash
python tools/serve.py 8765
```
Затем открой http://localhost:8765. Этот сервер отключает HTTP-кэш, поэтому правки видны сразу. Service worker всё равно кэширует файлы: после правок пересобери `sw.js` и перезагрузи страницу дважды.

## Публикация на GitHub Pages
1. Создай на github.com пустой публичный репозиторий `trenirovki-pwa`, без README.
2. В папке проекта выполни:
   ```bash
   git remote add origin https://github.com/<логин>/trenirovki-pwa.git
   git push -u origin main
   ```
3. Открой в репозитории Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение появится по адресу `https://<логин>.github.io/trenirovki-pwa/`.

## Установка на Android
1. Открой этот адрес в Chrome.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Один раз открой приложение с интернетом. Дальше оно работает в зале без сети.

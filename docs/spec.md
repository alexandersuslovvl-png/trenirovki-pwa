# Трекер тренировок (PWA) — спецификация

Дата: 2026-10-14. Источник программы и упражнений: `D:\Vault_Obsidian\Тренировки`.

## Цель
Мобильное офлайн-приложение (Android, Chrome) для тренировок по программе A/B/C:
отмечать старт и окончание упражнений, вес и повторы в каждом подходе, видеть технику,
тренажёр и рабочие мышцы прямо в карточке упражнения.

## Стек
Статический HTML + CSS + JS (ES-модули), без сборки и зависимостей. Хостинг — GitHub Pages.
Service worker кэширует всё приложение и картинки → работает без интернета.

## Экраны
1. **Главная** — выбор дня A/B/C (подсвечен следующий по очереди), продолжить незаконченную тренировку, история, резервная копия.
2. **Тренировка** — список упражнений дня со статусами, общий секундомер, «Завершить тренировку».
3. **Карточка упражнения** — анимация из двух фото, тренажёр, схема мышц (основные/вспомогательные), техника и ошибки (раскрываются), цель и прошлый результат, «Начать упражнение», блок подхода (вес/повторы ±, «Подход сделан»), таймер отдыха с вибрацией и звуком, подсказка «пора добавить вес», «Закончить упражнение».
4. **Итог** — длительность, число подходов, тоннаж, экспорт Markdown в формате дневника Obsidian.
5. **История** — список прошлых тренировок, открытие итога любой из них.

## Данные
- `js/data.js` — упражнения (тексты из атласа, тренажёр, мышцы, картинки) и программа A/B/C.
- Записи — `localStorage` (ключ `gym.v1`), запрос `navigator.storage.persist()`.
- Активная тренировка и таймер отдыха хранятся как метки времени → переживают перезагрузку.
- Резервная копия: экспорт/импорт JSON.

## Правила
- Значения веса/повторов в новом подходе подставляются из предыдущего подхода этой тренировки, иначе из первого подхода прошлого раза, иначе из нижней границы цели.
- «Пора добавить вес»: в прошлый раз во всех плановых подходах сделана верхняя граница повторов.
- Суперсет (день C) — одна карточка с двумя упражнениями, подход записывает обе пары вес × повторы.
- Во время тренировки экран не гаснет (Wake Lock API, если доступен).
